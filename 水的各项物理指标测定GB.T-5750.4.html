💧 GB/T 5750.4-2023 · 感官性状与物理指标

📋 生活饮用水标准检验方法 第4部分 | 完整操作规程（共10项）
🎨 色度 铂-钴标准比色法 ▼
1. 试剂准备
  • 纯水：蒸馏水经 0.22μm滤膜 过滤。
  • 铂-钴标准溶液（500度）：称取 1.246g 氯铂酸钾（K₂PtCl₆） 和 1.000g 干燥的六水合氯化钴（CoCl₂·6H₂O），溶于100mL纯水，加入100mL盐酸（ρ₂₀=1.19g/mL），用纯水定容至1000mL，混匀。
2. 仪器设备
  • 成套高型无色具塞比色管：50mL
  • 离心机（用于浑浊水样）
3. 样品采集与保存
  • 按GB/T 5750.2执行，样品应尽快测定，避免颜色变化。
4. 试验步骤
  • 4.1 样品处理：取 50mL 透明水样于比色管中。若浑浊，先离心或过滤。若色度过高，可取少量水样稀释后比色，结果乘以稀释倍数。
  • 4.2 标准系列配制：取11支比色管，分别加入铂-钴标准溶液 0, 0.50, 1.00, 1.50, 2.00, 2.50, 3.00, 3.50, 4.00, 4.50, 5.00 mL，加纯水至50mL刻度，摇匀，得到色度 0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50度 的标准色列。
  • 4.3 比色：将水样与标准色列在白色背景下 目视比较，找出最接近的色度。若色调不一致，描述为“异色”。
5. 结果计算
  • 色度（度）=（标准溶液用量mL × 500）/ 水样体积mL。若稀释，结果乘以稀释倍数。
  • 最低检测色度：5度，测定范围5～50度。
6. 质量要求
  • 目视比色应避免视觉疲劳，平行样测定偏差不超过10%。
🌫️ 浑浊度 散射法（福尔马肼标准） ▼
1. 试剂准备
  • 纯水：经0.22μm滤膜过滤。
  • 硫酸肼溶液（10g/L）：称取 1.000g 硫酸肼，溶于纯水并定容至100mL。
  • 六亚甲基四胺溶液（100g/L）：称取 10.00g 六亚甲基四胺，溶于纯水并定容至100mL。
  • 福尔马肼标准混悬液（400NTU）：分别吸取硫酸肼溶液和六亚甲基四胺溶液各 5.00mL 于100mL容量瓶，混匀，25℃±3℃放置24h，加纯水至刻度，混匀。可使用约1个月。
  • 福尔马肼标准使用液（40NTU）：将400NTU标准液用纯水稀释10倍。使用时再根据需要稀释。
2. 仪器设备
  • 散射式浑浊度仪（符合ISO 7027）
3. 样品采集与保存
  • 用清洁玻璃瓶采集，避免光照，尽快测定。
4. 试验步骤
  • 4.1 仪器校准：按仪器说明书，用零浊度水和福尔马肼标准液进行校准。
  • 4.2 样品测定：将摇匀的水样（无气泡）倒入测定管，放入仪器读取 NTU值。若浑浊度超过40NTU，用纯水稀释后测定，结果乘以稀释倍数。
5. 结果计算
  • 直接读取NTU，稀释后乘以倍数。最低检测值：0.5 NTU。
6. 注意事项
  • 硫酸肼具致癌毒性，操作时戴手套、口罩，避免吸入。
👃 臭和味 嗅气和尝味法 / 嗅阈值法 / 嗅觉层次分析法 ▼
方法一：嗅气和尝味法（6.1）
  • 仪器：250mL锥形瓶。
  • 步骤：取100mL水样于锥形瓶，振摇后闻气味；同时取少量品尝（仅限无毒水样）。按 六级强度（0无～5很强）记录。再将水样加热至沸腾，稍冷后重复嗅气和尝味。
  • 注：分析人员需满足无感冒、无异味等要求。
方法二：嗅阈值法（6.2）
  • 试剂：无臭水、2-甲基异戊醇标准品、土臭素标准品、硫代硫酸钠溶液（70g/L）等。
  • 步骤：取150mL水样于250mL具塞锥形瓶，60℃水浴加热5min，轻摇后闻气味。若有味，则用无臭水稀释，确定刚能闻出臭味时的稀释倍数，即嗅阈值（TON）。
  • 计算：TON = (水样体积+无臭水体积)/水样体积。多人测定取几何均数。
  • 精密度：生活饮用水RSD 0%～3.6%，水源水0%～6.7%。
方法三：嗅觉层次分析法（6.3）
  • 原理：3～5人组成评价小组，45℃水浴加热水样，闻臭气，单独评价异臭类型和强度（7级），再讨论确定。
  • 试剂：无臭水、已醛、2,6-壬二烯醛、土臭素、2-甲基异戊醇等标准品。
  • 步骤：取200mL水样于样品瓶，45℃水浴10～15min，闻测。记录异臭类型和强度等级（0～12级）。
  • 质量控制：每月进行加标试验，参考致臭物质（土霉味、黄瓜味等），相关系数应＞0.80。
👀 肉眼可见物 直接观察法 ▼
1. 仪器设备
  • 洁净透明的锥形瓶或烧杯。
2. 试验步骤
  • 将水样摇匀，倒入透明容器中，在 光线明亮处 迎光直接观察。
  • 记录所见 悬浮物、沉淀物、浮游生物 等，描述其形状、颜色、数量。
  • 结果报告：“有”或“无”肉眼可见物。
⚗️ pH值 玻璃电极法（8.1） ▼
1. 试剂准备
  • 标准缓冲溶液（现用现配或使用有证标准物质）：
    • • 邻苯二甲酸氢钾（pH 4.00 @20℃）：称取10.21g于105℃烘干2h的邻苯二甲酸氢钾，溶于水定容至1000mL。
    • • 混合磷酸盐（pH 6.88 @20℃）：称取3.40g磷酸二氢钾和3.55g磷酸氢二钠，溶于水定容至1000mL。
    • • 四硼酸钠（pH 9.22 @20℃）：称取3.81g十水合四硼酸钠，溶于水定容至1000mL。
  • 配制缓冲溶液所用纯水应为 新煮沸并放冷的蒸馏水，储存于聚乙烯瓶，可稳定1～2个月。
2. 仪器设备
  • 精密酸度计（精度≤0.02）
  • pH玻璃电极、饱和甘汞电极
  • 温度计（0～50℃）
  • 塑料烧杯（50mL）
3. 试验步骤
  • 3.1 电极处理：玻璃电极在使用前应放入纯水中浸泡 24h以上。
  • 3.2 仪器校正：开机预热30min，选用一种与被测水样pH接近的标准缓冲溶液进行 定位，再用另一标准液 复定位（如pH<7用邻苯二甲酸氢钾定位，四硼酸钠复定位；pH>7反之）。
  • 3.3 测定：用纯水淋洗电极，再用水样淋洗6～8次，插入水样中，1min后读取pH值，精确至 0.01。
4. 注意事项
  • pH值宜 现场测定，水样保存时间短。
  • 甘汞电极内应保持有氯化钾晶体，保证饱和状态。
  • pH>9时需使用高碱玻璃电极。
⚡ 电导率 电极法（9.1） ▼
1. 试剂准备
  • 氯化钾标准溶液 [c(KCl)=0.01000mol/L]：称取 0.7456g 优级纯氯化钾（110℃烘干），溶于新煮沸冷却的纯水中（电导率＜1μS/cm），于25℃定容至1000mL。此溶液25℃电导率为 1413 μS/cm，储于塑料瓶中。
2. 仪器设备
  • 电导仪（带温度补偿）
  • 恒温水浴（控温±0.1℃）
3. 试验步骤
  • 3.1 恒温：将氯化钾标准溶液和水样同置于25℃±0.1℃水浴中加热30min。
  • 3.2 测定电导池常数：用氯化钾溶液冲洗电极和电导池，测量其电导 GKCl，计算电导池常数 C = 1413 / GKCl。
  • 3.3 测定水样：用水样冲洗电极，测量水样电导 Gs，计算电导率 γ = C × Gs（μS/cm）。
4. 结果报告
  • 报告25℃时的电导率（μS/cm），非25℃需温度校正。
🧂 总硬度 EDTA滴定法（10.1） ▼
1. 试剂准备
  • 缓冲溶液（pH=10）：称取16.9g氯化铵溶于143mL氨水（ρ=0.88g/mL），另取0.780g MgSO₄·7H₂O和1.178g Na₂EDTA·2H₂O溶于50mL水，加2mL上述氨性溶液和5滴铬黑T，用EDTA滴至纯蓝色，合并两液，用水稀释至250mL。
  • 铬黑T指示剂（5g/L）：0.5g铬黑T溶于95%乙醇，定容至100mL，冰箱保存，可稳定1个月。
  • EDTA标准溶液 [c≈0.01mol/L]：称取3.72g Na₂EDTA·2H₂O溶于水定容至1000mL，用锌标准溶液标定。
  • 硫化钠溶液（50g/L）、盐酸羟胺溶液（10g/L）、氰化钾溶液（100g/L）（剧毒！）用于消除干扰。
2. 仪器设备
  • 150mL锥形瓶，10mL或25mL滴定管。
3. 试验步骤
  • 3.1 取样：取 50.0mL 水样（硬度高时取适量稀释至50mL；硬度低时取100mL）于锥形瓶。
  • 3.2 滴定：加入1～2mL缓冲液，5滴铬黑T指示剂，立即用EDTA标准溶液滴定，溶液由 紫红色 变为 纯蓝色 为终点，同时做空白试验。
  • 3.3 干扰消除：若终点延迟或变色不敏锐，可另取水样加入盐酸羟胺和硫化钠（或氰化钾）后再滴定。
4. 结果计算
  • 总硬度（以CaCO₃计，mg/L）= (V₁－V₀) × c × 100.09 × 1000 / V
  • 其中 V₁ 为样品消耗EDTA体积（mL），V₀ 空白体积，c 为EDTA浓度（mol/L），V 为水样体积（mL）。
  • 最低检测质量浓度：1.0 mg/L（取50mL）
5. 警示
  • ⚠️ 氰化钾溶液剧毒！操作时严格戴手套、护目镜，在通风橱内进行，废液需专门处理。
⚖️ 溶解性总固体 称量法（105℃或180℃烘干） ▼
1. 试剂准备
  • 碳酸钠溶液（10g/L）（用于180℃烘干法）：称取10g无水碳酸钠溶于水定容至1000mL。
2. 仪器设备
  • 天平（分辨力0.0001g）
  • 水浴锅、电热恒温干燥箱
  • 100mL瓷蒸发皿、干燥器（硅胶）
  • 中速定量滤纸或0.45μm滤膜及滤器
3. 试验步骤（105℃烘干）
  • 3.1 恒重蒸发皿：将蒸发皿洗净，于105℃±3℃烘30min，干燥器冷却30min，称量，重复至恒重（两次称量差≤0.0004g）。
  • 3.2 过滤水样：将水样上清液过滤。
  • 3.3 蒸发：吸取 100mL 滤液于蒸发皿，水浴蒸干。
  • 3.4 烘干称量：将蒸发皿移入105℃烘箱1h，取出冷却30min称量，再烘30min至恒重。
4. 试验步骤（180℃烘干）
  • 蒸发皿在180℃±3℃烘干至恒重。
  • 取100mL水样，精确加入 25.0mL 碳酸钠溶液，混匀，同时做空白（加25.0mL碳酸钠溶液）。蒸干后180℃烘干至恒重，结果减去空白质量。
5. 结果计算
  • ρ(TDS) = (m₁－m₀) × 1000 / V （mg/L）
  • m₁：蒸发皿+残渣质量（mg），m₀：蒸发皿质量（mg），V：水样体积（mL）。
🧪 挥发酚类 4-氨基安替比林萃取分光光度法（12.1） ▼
1. 试剂准备
  • 无酚纯水：于水中加NaOH至pH>12，蒸馏。
  • 硫酸铜溶液（100g/L）：10g CuSO₄·5H₂O溶于水定容至100mL。
  • 氨水-氯化铵缓冲液（pH9.8）：20g NH₄Cl溶于100mL氨水（ρ=0.88g/mL）。
  • 4-氨基安替比林溶液（20g/L）：2.0g 4-AAP溶于水定容至100mL，棕色瓶，现配。
  • 铁氰化钾溶液（80g/L）：8.0g K₃Fe(CN)₆溶于水定容至100mL，棕色瓶，现配。
  • 酚标准储备溶液：精制苯酚配制并标定，或使用有证标准物质。
  • 酚标准使用液（1.00μg/mL）：临用前稀释。
  • 溴酸钾-溴化钾溶液 [c(1/6KBrO₃)=0.1mol/L]、淀粉溶液（5g/L）、硫代硫酸钠标准溶液（0.0500mol/L）等用于标定。
2. 仪器设备
  • 500mL全玻璃蒸馏器（避免橡胶连接）
  • 500mL分液漏斗、10mL具塞比色管
  • 分光光度计
3. 试验步骤
  • 3.1 蒸馏：取 250mL 水样于蒸馏瓶，加甲基橙指示剂，用硫酸调至橙色（pH<4），加5mL硫酸铜和数粒玻璃珠，加热蒸馏，收集 250mL 馏出液。
  • 3.2 显色萃取：将馏出液转入分液漏斗。另取标准使用液 0, 0.50, 1.00, 2.00, 4.00, 6.00, 8.00, 10.00 mL 于盛有100mL纯水的分液漏斗中，补加水至250mL。各加2mL缓冲液，1.50mL 4-AAP溶液，混匀，再加1.50mL铁氰化钾，混匀，静置10min。加入10.0mL三氯甲烷，振摇2min，静置分层。
  • 3.3 测定：将三氯甲烷层放入干燥比色管，于 460nm 波长，2cm比色皿，以三氯甲烷为参比，测吸光度。
  • 3.4 标准曲线：绘制标准曲线，查出样品中酚的质量（μg）。
4. 结果计算
  • 挥发酚（以苯酚计，mg/L）= m / V（m为从标准曲线查得质量，μg；V为水样体积，mL）。
  • 最低检测质量浓度：0.002 mg/L（取250mL）
5. 干扰消除
  • 硫化物、余氯、苯胺类、石油等干扰；蒸馏可分离硫化物，余氯加硫酸亚铁或亚砷酸钠还原，苯胺在酸性下不被蒸出，石油可用有机溶剂萃取除去。
🧼 阴离子合成洗涤剂 亚甲基蓝分光光度法（13.1） ▼
1. 试剂准备
  • 亚甲基蓝溶液（0.03g/L）：称取30mg 三水合亚甲基蓝，溶于500mL纯水，加6.8mL硫酸和50g NaH₂PO₄·H₂O，定容至1000mL。
  • 洗涤液：6.8mL硫酸和50g NaH₂PO₄·H₂O溶于水定容至1000mL。
  • 氢氧化钠溶液（40g/L）、硫酸溶液 [c(1/2H₂SO₄)=0.5mol/L]。
  • 十二烷基苯磺酸钠（DBS）标准储备液（1mg/mL）：称取0.500g DBS溶于水定容至500mL（或使用有证标准物质）。
  • DBS标准使用液（10μg/mL）：取储备液100.0mL定容至1000mL。
  • 酚酞溶液（1g/L）。
  • 三氯甲烷（萃取溶剂）。
2. 仪器设备
  • 分光光度计
  • 25mL比色管
  • 125mL分液漏斗
3. 试验步骤
  • 3.1 标准系列：取7个分液漏斗，分别加入DBS标准使用液 0, 0.50, 1.00, 2.00, 3.00, 4.00, 5.00 mL，用水补至50mL。
  • 3.2 样品：取 50.0mL 水样（若浓度过高则稀释至50mL，若过低则增加体积并使标准系列一致）。
  • 3.3 显色萃取：向样品和标准系列中各加3滴酚酞，用NaOH调至碱性，再用硫酸调至红色刚褪。加入5mL三氯甲烷和10mL亚甲基蓝溶液，剧烈振摇30s，静置分层。
  • 3.4 洗涤：将三氯甲烷相转入第二套分液漏斗，加入25mL洗涤液，振摇30s，静置。
  • 3.5 测量：将三氯甲烷相放入25mL比色管，再用5mL三氯甲烷重复萃取两次，合并萃取液，用三氯甲烷定容至刻度。于 650nm，3cm比色皿，以三氯甲烷为参比，测吸光度。
4. 结果计算
  • 阴离子合成洗涤剂（以DBS计，mg/L）= m / V（m为从标准曲线查得质量，μg；V为水样体积，mL）。
  • 最低检测质量浓度：0.050 mg/L（取100mL）
5. 干扰及消除
  • 酚、有机硫酸盐、磷酸盐、大量氯化物、硝酸盐等干扰。本方法可通过洗涤液减少干扰。
6. 其他方法
  • 标准中还包括 二氮杂菲萃取分光光度法（13.2）、流动注射法（13.3）、连续流动法（13.4），可参考标准原文选择。
📌 方法说明与安全警示：
📖 本规程依据 GB/T 5750.4-2023 编制，涵盖10项感官性状与物理指标。
⚠️ 涉及 氰化钾（总硬度）和 三氯甲烷（挥发酚、洗涤剂）等有毒试剂，操作须在通风橱内进行，佩戴防护手套、护目镜，废液按危险废物处置。
🧪 挥发酚类、阴离子合成洗涤剂另有 流动注射法 和 连续流动法，如需自动化分析可选用。
🌡️ pH值、电导率宜 现场测定；溶解性总固体烘干温度可根据样品选择105℃或180℃。
